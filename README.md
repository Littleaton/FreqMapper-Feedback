# FreqMapper Feedback

Welcome to FreqMapper's public feedback tracker. Use this repository to report reproducible bugs and suggest practical improvements for the wardriving and Meshtastic coverage-mapping experience.

## Before opening an issue

- Use the **Bug report** form when something did not work as expected. Include clear steps so it can be reproduced.
- Use the **Feature request** form for an improvement or new idea.
- Do **not** include channel keys, PSKs, API keys, tokens, private messages, or precise private/home locations.

The FreqMapper implementation repository and operational configuration are intentionally not published here. This project is only for community feedback and issue tracking.
